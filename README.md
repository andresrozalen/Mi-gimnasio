# Mi Gimnasio

Aplicación personal de entrenamiento con registro de cuatro series: 12, 10, 8 y 6 repeticiones.

## Funciones

- Ejercicios por grupo muscular y fichas personalizables.
- Registro de cargas, repeticiones y notas; historial, gráfica y mayor carga registrada.
- Temporizador de descanso y orientación de progresión.
- Edición de registros y papelera recuperable.
- Almacenamiento local y exportación/restauración de copias JSON.
- Preparación para uso sin conexión tras la primera carga completa.

## iPhone

Abre la dirección HTTPS del sitio en Safari y utiliza Compartir → Añadir a pantalla de inicio. Verifica el funcionamiento sin conexión después de cargarla una vez con conexión.

## Datos y privacidad

Los entrenamientos se guardan en el almacenamiento del navegador de cada dispositivo. No se sincronizan automáticamente ni se incluyen en este repositorio. El código y los ejercicios predeterminados son públicos.

Exporta periódicamente una copia JSON y comprueba que el archivo se haya guardado. Borrar los datos del sitio o cambiar de navegador, dispositivo o dirección puede hacer necesario restaurar esa copia. Las copias JSON no están cifradas: no las subas al repositorio.

GitHub Pages puede registrar datos técnicos de acceso, como la dirección IP, conforme a su política de privacidad.

## Notas

Sin cuentas en la aplicación, pagos ni dependencias externas. El temporizador muestra un aviso dentro de la app; no garantiza notificaciones o sonido con el teléfono bloqueado. La orientación de progresión no sustituye la valoración de técnica, fatiga y recuperación.
